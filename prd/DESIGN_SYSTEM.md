# Elite Weavers Design System

## Design read
Luxury Indian heritage meets modern fashion editorial. Design variance 8, motion intensity 6, visual density 4.

## Palette
- Night `#09151f`: primary dark surface and hero ink.
- Deep tide `#102735`: secondary dark surface.
- Silk ivory `#f0eee8`: warm-neutral page surface.
- Saffron thread `#e0ad62`: single accent for action, focus, and craft highlights.
- Sage mist `#b8c5bc`: editorial wash and soft section surface.
- Indigo `#182c48`: collection depth.

The page uses one accent color and stays in a single dark-to-ivory heritage theme rather than switching into unrelated color blocks.

## Typography
- Display: Playfair Display, used for editorial headlines and product names.
- Interface: DM Sans, used for body copy and controls.
- Metadata: Manrope, used for navigation, labels, and commerce metadata.
- Headlines are sentence case, left aligned where possible, with italic emphasis reserved for editorial tone.

## Spacing
Base unit is 4px. Common rhythm: 8, 12, 16, 24, 32, 48, 72, 96, 120, 160px. Desktop content uses 4vw side gutters; mobile uses 20-24px.

## Shape and depth
The primary system is sharp-edged editorial rectangles. Pills are reserved for quantity controls and compact status. Shadows are tinted dark navy and used only for overlays and drawers.

## Components
- Header: 29px announcement strip, 74px desktop navigation, 67px mobile navigation.
- Primary button: saffron fill, night text, uppercase Manrope metadata, tactile translate on hover and active.
- Quiet link: text link with a hairline underline.
- Product card: image-first, minimal metadata, no heavy container.
- Drawer: right-side bag and wishlist surfaces with scrim and focusable close control.
- Modal: quick view with image, concise story, price, and add action.
- Filter controls: text tabs and select controls, never decorative chips over photography.
- Toast: short confirmation with explicit action context.
- Input: visible label above field, high-contrast underline, visible focus ring.

## Patterns
Use asymmetric collection grids, editorial split stories, a single marquee, horizontal product rows, and image-led cards. Do not repeat the same three-card layout in every section. Keep eyebrows sparse and functional.

## Accessibility
All controls have labels, focus-visible outlines use saffron, body text targets WCAG AA contrast, images have alt text, dialogs close with explicit controls, and reduced motion disables looping patterns, parallax, and entrance movement.
