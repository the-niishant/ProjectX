# Elite Weavers UX Flow

## Browse
Home hero CTA enters New arrivals. Collection tiles enter a category-filtered product view. Header search opens an inline field and returns matching products.

## Discover
Shopper chooses category, fabric, color, occasion, and price controls. Sort can be curated, price low to high, or price high to low. Empty results offer a single reset action.

## Product
Shopper opens quick view for a lightweight decision or product detail for full gallery, craft, care, delivery, reviews, and related pieces. Quantity is selected before adding.

## Wishlist
Heart control saves or removes a piece and updates the header count. Wishlist has an empty state with a route back to the edit. Saved items can be added to bag.

## Cart
Add-to-bag confirms the item, opens the cart drawer on explicit Bag action, and retains quantity state. Shopper can update quantity, remove a line, apply a promo code, and view shipping threshold.

## Checkout
Checkout asks for contact, shipping, delivery, and payment information with labels and inline errors. Order summary remains visible on desktop and stacks above the submit action on mobile. Demo submit shows a confirmation state and clears the active bag.

## Failure and empty states
Search empty state explains how to broaden the search. Empty wishlist and cart point back to collections. Form errors name the field and action needed. Loading uses image-shaped skeleton blocks rather than a generic spinner.
